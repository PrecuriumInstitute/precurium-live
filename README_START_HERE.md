## Upload auf GitHub Pages
1. Inhalt dieses Ordners in das GitHub-Repository hochladen/ersetzen.
2. GitHub Pages auf `main` / root aktivieren.
3. Unter Settings → Pages `precurium.com` als Custom Domain prüfen.
4. `Enforce HTTPS` aktivieren.
5. Nach Livegang `https://precurium.com/robots.txt` und `https://precurium.com/sitemap.xml` testen.
6. Danach Google Search Console anbinden und die Sitemap `https://precurium.com/sitemap.xml` einreichen.
